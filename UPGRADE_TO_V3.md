# Upgrade to Companion Forge v3 — Historical Address

This path is retained so old bookmarks and installed companions do not reach a
dead end. It formerly carried the version 3 migration procedure.

Use the permanent [`UPGRADE.md`](./UPGRADE.md) path instead. It recognizes
unversioned, pre-v3, and v3 companions; keeps each companion on its current
platform; preserves its personal layer and records; and migrates it to one
verified complete present release without mixing versions.

The v3 release and its original migration decision remain documented in
[`CHANGELOG.md`](./CHANGELOG.md) and
[`decision_journal.md`](./decision_journal.md).
